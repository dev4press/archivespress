An authors index links to authors with published, non-password-protected content in the selected post type. Counts reflect matching posts for each author.

## Choose the layout and order

Basic arranges authors in columns; choose from one to six. Compact displays items in a wrapping row instead, so its item widths are not controlled by the column setting. The Basic layout can use fewer columns on smaller screens.

Choose **Order By** to sort by post count, ID, name, slug, or email, and **Order** for ascending or descending results. For example, select Name and Ascending for an alphabetical list.

## Avatars and counts

Use the avatar control to show or hide author images and adjust their size. Turn counts on or off independently. In the block editor, **Typography** and **Colors** control the index appearance; Elementor offers additional styling in its **Style** tab.

Author links use standard WordPress author archive URLs unless customized. When indexing a custom post type, check the destination archive to make sure it includes the content you expect.
