# Does ArchivesPress require Elementor?

<!-- type: faq -->
<!-- category: getting-started -->
<!-- tag: elementor,blocks -->
<!-- seo-title: %%post_title%% - %%sitetitle%% -->
<!-- seo-description: Find out whether ArchivesPress requires Elementor. -->
<!-- seo-keywords: archivespress,elementor,blocks -->

No. Elementor is optional; you can use [blocks](blocks-support.md) or shortcodes without it. To use the [Elementor widgets](elementor-support.md), activate Elementor 3.1 or newer.
