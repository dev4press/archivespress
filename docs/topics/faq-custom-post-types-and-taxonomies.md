# Can I use custom post types and taxonomies?

<!-- type: faq -->
<!-- category: getting-started -->
<!-- tag: post-types,taxonomies -->
<!-- seo-title: %%post_title%% - %%sitetitle%% -->
<!-- seo-description: Use custom post types and taxonomies in ArchivesPress indexes. -->
<!-- seo-keywords: archivespress,custom post types,taxonomies -->

Yes. Select a public post type and, for a terms index, a public taxonomy registered for that post type. Check archive destinations for custom post types: date and author links use standard WordPress archive URLs by default.

See [terms archives index](terms-index.md) and [troubleshooting](troubleshooting.md) for more details.
