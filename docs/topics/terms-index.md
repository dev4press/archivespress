A terms index links to categories, tags, or another public taxonomy's terms. Choose a public post type and a public taxonomy registered for that post type. Only terms assigned to published, non-password-protected posts of that type are included; the count for a term reflects those matching posts.

## Choose the layout and order

Basic arranges terms in one to six columns and can use fewer columns on smaller screens. Compact displays terms in a wrapping row, where the column setting does not control item widths.

Choose **Order By** to sort by post count, ID, name, or slug, and **Order** for ascending or descending results. For an alphabetical list, select Name and Ascending. You can also show or hide counts and adjust typography and colors.

## Check the taxonomy

The taxonomy must be registered for the selected post type. If the index is empty, check the post type, taxonomy, and term assignments. See [troubleshooting](troubleshooting.md).
