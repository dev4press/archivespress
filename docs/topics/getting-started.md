ArchivesPress creates indexes that help visitors navigate to date, author, and taxonomy archives. Choose a block, shortcode, or Elementor widget and configure each index where you insert it. There is no global settings page.

1. [Install the plugin](install-and-update.md).
2. Choose an index: [dates](dates-index.md), [authors](authors-index.md), or [terms](terms-index.md).
3. Add it using the [block editor](blocks-support.md), [Elementor](elementor-support.md), or a shortcode.
4. Publish the page and check its links and appearance on the front end.

For a walkthrough from installation to a finished index, see the [Ultimate Guide to ArchivesPress](ultimate-guide-to-archivespress.md). For help with empty indexes or unexpected links, see [troubleshooting](troubleshooting.md).
