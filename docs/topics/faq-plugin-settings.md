# Where are the plugin settings?

Each block, shortcode, or widget has its own options. ArchivesPress does not add a global settings page.

Select a block in the editor to use its settings sidebar, or select a widget in Elementor to use its Content and Style controls. See [using blocks](blocks-support.md) and [using Elementor widgets](elementor-support.md).
