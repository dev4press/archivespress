Output
HTML index of matching terms, or an empty string when selection is invalid or no data exists.

Indexes terms assigned to published, non-password-protected posts. The definition shows example attributes, not a complete list. Style values are validated before output: font sizes require an accepted unit (except zero), line heights may be unitless or use px, em, rem, or %, and colors must use a supported color syntax. Invalid values are ignored.
