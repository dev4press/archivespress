Output
HTML index of matching dates, or an empty string when the post type is invalid or no data exists.

Indexes published, non-password-protected posts by date. Compact falls back to basic when year is hidden. The definition shows example attributes, not a complete list. Style values are validated before output: font sizes require an accepted unit (except zero), line heights may be unitless or use px, em, rem, or %, and colors must use a supported color syntax. Invalid values are ignored. Date links use WordPress archive URLs by default, including for custom post types.

Example

[[archivespress-dates years="2024,2025" show-day-counts="true"]]
