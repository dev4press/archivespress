Definition
apply_filters( "archivespress-terms-get-term-link-{post_type}", $url, $term );
Arguments
Name
Type
Description
$url
null|string
Initially null; optional replacement archive URL.
$term
int|string
Term ID.
Returns
Return an archive URL string or null to use the WordPress fallback.

The {post_type} placeholder is replaced by the selected post type slug; for example, use archivespress-terms-get-term-link-post. Return null to use get_term_link(). The hook does not receive the post type as a separate argument. The taxonomy is used by the fallback but is not passed to this filter. A non-string result after fallback produces an empty URL.
