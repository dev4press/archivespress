Definition
apply_filters( "archivespress-authors-avatar", $avatar, $info, $size );
Arguments
Name
Type
Description
$avatar
null|string
Initially null; custom avatar markup.
$info
array
Author data including id, name, slug, email, and posts.
$size
int
Requested avatar size in pixels.
Returns
Return null to use WordPress get_avatar(), or return custom avatar HTML.

Runs for each author only when the configured avatar size is greater than zero. A non-null result is used as the avatar markup; return trusted HTML.
