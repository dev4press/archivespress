Definition
apply_filters( "archivespress-authors-post-types", $post_type );
Arguments
Name
Type
Description
$post_type
string
Default public post type for the shortcode; initially post.
Returns
Return a public post type slug.

Filters the default post type when the authors shortcode is initialized. It does not override a post_type attribute supplied by a shortcode, block, or widget.

Example

add_filter( 'archivespress-authors-post-types', function ( $post_type ) {
    return 'post';
} );
