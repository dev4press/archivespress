Definition
apply_filters( "archivespress-terms-cache-object", $object );
Arguments
Name
Type
Description
$object
null|iCache
Initially null. Provide an object implementing Dev4Press\Plugin\ArchivesPress\Base\iCache, or leave null to use the built-in implementation.
Returns
Return null for the built-in implementation or an object implementing iCache.

Filters the terms cache implementation each time it is requested. The replacement must satisfy the declared interface. Returning a falsey value selects the built-in implementation.
