Definition
apply_filters( "archivespress-dates-get-day-link-{post_type}", $url, $year, $month, $day );
Arguments
Name
Type
Description
$url
null|string
Initially null; optional replacement archive URL.
$year
int|string
Archive year.
$month
int|string
Archive month.
$day
int|string
Archive day.
Returns
Return an archive URL string or null to use the WordPress fallback.

The {post_type} placeholder is replaced by the selected post type slug; for example, use archivespress-dates-get-day-link-post. Return null to use get_day_link(). The hook does not receive the post type as a separate argument.
